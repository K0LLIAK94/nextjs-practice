# Проверка практической работы

## Автоматические проверки

| Проверка | Результат |
| --- | --- |
| `npm run build` | Успешная production-сборка |
| `npm run lint` | Без ошибок |
| `npm run typecheck` | Без ошибок TypeScript |
| Тип маршрутов в сборке | `/` — статический; `/articles` и `/articles/[id]` — динамические |

## Проверки в Chromium

- Каталог получает реальные данные JSONPlaceholder и содержит 15 карточек.
- Название отдельной статьи совпадает с title вкладки; description содержит первые 160 символов текста.
- Навигация через Link сохраняет браузерный контекст без полной перезагрузки страницы.
- Кнопка возврата открывает `/articles`, в том числе после прямого входа на страницу статьи.
- `/articles/999999`, `/articles/abc` и `/unknown` показывают not-found и метатег `noindex`.
- На ширине 390 px нет горизонтальной прокрутки.
- HTML ответа содержит заголовки и ссылки на все 15 статей даже без выполнения JavaScript. Видимость потоковой разметки описана в README.
- Во время искусственной задержки серверного API отображается `loading.tsx`.
- При искусственном ответе API 503 отображается `error.tsx`; после восстановления API кнопка повторной попытки снова показывает 15 статей.
- В обычных сценариях нет необработанных ошибок JavaScript страницы.

Скриншоты главной, каталога и мобильного каталога находятся в `screenshots/`. Тестовая имитация задержек и сбоев использовалась только при проверке: приложение всегда обращается к заданному API.
